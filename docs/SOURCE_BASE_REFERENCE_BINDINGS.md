# Привязка Source-ссылки к базовому подобъекту

Source Parser V2 принимает привязку ссылки на базовый класс к производному
объекту, в том числе через другую ссылку:

```cpp
struct Prefix { int pad = 123; };
struct Base { int value = 7; };
struct Mid : Base {};
struct Derived : Prefix, Mid {};
// Source:
Derived d;
Derived& input;
input = d;
Base& alias;
alias = input;
alias.value = 19;
```

Источник связи получает явные шаги разыменования и переходов к базовым
подобъектам. Graph не ослабляет равенство несвязанных типов: связь относится
к конкретному Base внутри Derived, с корректным ненулевым ABI-смещением.
Неоднозначные, закрытые и обратные преобразования отклоняются. Добавление
const/volatile для совместимого типа проверяется одинаково Graph и аудитом
compiled-данных; снятие квалификаторов запрещено.

Также исправлено стандартное преобразование массива (в том числе ссылки на
массив) в указатель в присваивании `p = array`: сохраняется endpoint первого
элемента, а не адрес копии массива.

Frontend regressions и compiled_project tests проходят. TCP PUBLISH, LOAD и
LOAD в новом процессе подтверждают `d.value = alias.value = 19`,
`d.pad = 123`, чтение через const-ссылку и значение 23 через указатель на первый
элемент массива. Результат: `build/unitprotr-base-reference-tcp-final/summary.json`.

Полный PUBLISH UnitProTr проходит прежние привязки `U_DDT&` и указатели на
массивы. Последующая остановка на аннотации Studio `HIDDEN` устранена удалением
этих токенов из копий Source при переносе. Оригиналы экспорта не изменяются.
Актуальный результат проверки: `examples/UnitProTr/validation.json`.
