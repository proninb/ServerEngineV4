# Разбор конструкторов с параметрами

Header Parser V2 принимает объявления перегруженных конструкторов до и после
конструктора по умолчанию, включая указатели, ссылки, несколько параметров,
значения аргументов по умолчанию, указатели на функции и массивы.

```cpp
struct A {
    int value;
    A(const int*);
    A(const A&) = default;
    A(int v) noexcept(true) : value(v) { value = 99; }
    A() : value(7) {}
};
```

Списки параметров и тела конструкторов с параметрами разбираются как
сбалансированные токены. Поддержаны `noexcept`, `noexcept(...)`, `= default`,
`= delete`, списки инициализации и определения с телом. Проверяются закрытие
и соответствие скобок, пустые элементы списка параметров и завершение
декларации. Это разбор поддержанного подмножества C++, а не полная проверка
типов и выражений внутри тела.

Перегруженные конструкторы не исполняются и не добавляют инициализации в Graph.
В примере значение при автоматическом создании A остаётся 7. Существующий
разбор managed-конструктора по умолчанию сохранён; `A(void)` считается
конструктором без параметров, повторный managed default отклоняется.

Frontend regressions проходят, включая объявления из UnitProTr,
перегрузки, определения, сохранение default-значений и ошибочные входы.

Тела обычных методов, деструкторов и операторов также разбираются как
сбалансированные токены без выполнения. Вложенные блоки, скобки, комментарии
и строковые литералы не нарушают границы тела; несогласованные или незакрытые
скобки отклоняются. Тело после `= default`, `= delete` или `= 0` недопустимо.
Инициализации полей до и после метода сохраняются, записи методов и их локальные
переменные не добавляются в Graph.

Все заголовки UnitProTr проходят разбор. Индексирование `ANA_CH_IN[0]` также
исправлено; см. `SOURCE_ARRAY_REFERENCE_INDICES.md`.
