# Присваивания унаследованным полям в конструкторах

Header Parser V2 поддерживает присваивание скалярных констант унаследованным
полям в теле конструктора, в том числе констант enum:

```cpp
enum Kind { NONE, BOOL };
struct Base { unsigned char type = NONE; };
struct Derived : Base { Derived() { type = BOOL; } };
```

Переопределение принадлежит производному типу. Значение базового типа не
изменяется. Поддержаны несколько уровней наследования и ненулевые смещения
баз при множественном наследовании. Собственное поле производного типа
скрывает одноимённое базовое поле; последнее присваивание определяет значение.

Неоднозначные имена, закрытые унаследованные поля, несовместимые значения и
инициализация унаследованного поля через список `Derived() : type(BOOL)`
отклоняются. Поддержка относится к скалярным константам, а не выполнению
произвольного кода конструктора.

Один алгоритм поиска поля используется парсером, проверкой compiled-данных и
обоими путями материализации runtime. Сохраняются существующие записи
constructor_defaults; ABI-смещения в compiled-данные не добавляются.

Проверки: frontend regressions и compiled_project tests проходят. Реальная
TCP-проверка PUBLISH, LOAD и LOAD в новом процессе подтверждает значения
`base.type = 0`, `derived.type = 1`, `derived.pad = 123`.
Результаты: `build/unitprotr-inherited-tcp-final/summary.json`.

UnitProTr проходит прежнюю ошибку `type = U_TYPE_BOOL`. Дополнительно реализованы
десятичные литералы с суффиксом `f`/`F` (с округлением до float перед сохранением
канонического double, включая отрицательный ноль) и объявления инкремента и
декремента с пустым списком параметров либо одним `int`.

Конструкторы с параметрами и тела методов также разбираются без выполнения.
Индексирование `ANA_CH_IN[0]` также исправлено; см.
`SOURCE_ARRAY_REFERENCE_INDICES.md` для текущего состояния проверки UnitProTr.
